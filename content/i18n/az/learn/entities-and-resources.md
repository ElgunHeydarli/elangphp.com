# Entity əsasında JSON cavab qurun

Ön şərt: verilənlər bazası dərsi və miqrasiyalar. Məqsəd: real entity əlaqəsini, açıq JSON resursunu və kolleksiya hesabını birləşdirmək.

Kataloq nümunəsini işlədin. Entities və ProductResource fayllarını açın. Sorğu kateqoriyanı fetch join ilə alır, resurs daxili qeydi göstərmir. İki test miqdarını və gözlənilən cəmi birlikdə dəyişib yenidən işlədin.

```bash
php vendor/elang/framework/examples/orm-catalog/run.php
```

Nəticə düzgündürsə və API-də məxfi sahə yoxdursa tapşırıq hazırdır. Daimi tətbiq üçün yoxlanmış miqrasiya yazın; yazma əməliyyatından əvvəl autentifikasiya və sahiblik şərtlərini əlavə edin.
