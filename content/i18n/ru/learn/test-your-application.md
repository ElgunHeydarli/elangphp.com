# Проверьте поведение до развёртывания

Требуются два предыдущих практических урока. Цель: через реальный kernel проверить JSON, записи в базе, скрытие приватных полей и внешний API-адаптер.

Запустите каталог и прочитайте проверки TestClient. Задайте неверное ожидаемое JSON-значение, убедитесь в ошибке и исправьте его. Создайте отдельный тест по главе тестирования. До развёртывания добавьте отказ в доступе и ошибку CSRF.

```bash
php vendor/elang/framework/examples/orm-catalog/run.php
```

Задание выполнено, когда положительные и отрицательные сценарии проходят на изолированной базе без реальных писем и внешних запросов. Тесты framework не заменяют проверки ваших разрешений и бизнес-правил.
