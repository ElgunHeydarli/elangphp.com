# Постройте JSON-ответ на основе сущностей

Требуются урок базы и миграции. Цель: объединить реальные связи сущностей, явный JSON-ресурс и расчёт коллекции.

Запустите каталог ниже. Откройте Entities и ProductResource. Запрос делает fetch join категории, ресурс исключает внутреннюю заметку. Измените оба демонстрационных количества и ожидаемую сумму, затем повторите запуск.

```bash
php vendor/elang/framework/examples/orm-catalog/run.php
```

Задание выполнено при правильном результате и отсутствии приватного поля в API. Для постоянного приложения подготовьте миграцию; перед записью подключите аутентификацию и ограничения владельца.
