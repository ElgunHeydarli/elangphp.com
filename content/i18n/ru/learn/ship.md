# Подготовка к развёртыванию

Работающее локальное приложение требует явной настройки перед публикацией в интернете.

## Проверка приложения

Проверьте валидацию, решения об авторизации, запросы к базе данных и поведение ошибок. Запустите набор тестов. Тесты фреймворка не заменяют тесты конкретного приложения.

## Подготовка зависимостей

```bash
composer install --no-dev --prefer-dist --optimize-autoloader
```

Установите `APP_ENV=production`, `APP_DEBUG=false`, канонический APP_URL и ключ приложения. Храните секреты и доступные для записи файлы в закрытом доступе.

## Настройка корневого веб-каталога

Откройте доступ только к `public/`. Настройте PHP-FPM и передавайте несуществующие пути в `index.php`. Руководство по развёртыванию содержит рекомендации для Apache и Nginx.

## Применение изменений схемы

Проверьте ожидающие миграции и создайте резервную копию важных данных перед выполнением `php elang migrate --force`. После развёртывания проверьте типичные страницы, ошибки JSON и журналы.

## Учитывайте статус выпуска

Elang 0.1 — предварительная версия для разработчиков с изменяющимися API. Используйте её для оценки и контролируемых проектов, пока продолжаются проверки совместимости и безопасности.
