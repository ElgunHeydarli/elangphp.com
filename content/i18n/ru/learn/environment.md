# Настройка PHP и Composer для Elang

К концу этого урока ваш терминал будет запускать PHP и Composer, а Elang doctor объяснит, готов ли проект к работе. Устанавливать фреймворк для интерфейса не нужно.

## Перед началом

Используйте компьютер, на котором можно устанавливать инструменты разработки, текстовый редактор и терминал. Терминал выполняет команды; это не то же самое, что вводить PHP в адресную строку браузера. Запускайте каждую команду из каталога, указанного в уроке.

Elang требует PHP 8.3 или новее в пределах ветки PHP 8.x. Если PHP уже установлен, проверьте версию перед установкой ещё одной копии. На компьютере с несколькими установками PHP Composer и веб-сервер могут использовать разные из них.

## Настройка Windows

1. Следуйте [официальным инструкциям по установке PHP в Windows](https://www.php.net/manual/en/install.windows.php) и установите поддерживаемую сборку PHP 8.x для своей системы.
2. Добавьте каталог с `php.exe` в пользовательскую переменную PATH. Создайте рекомендуемый php.ini из поставляемого шаблона разработки, если ваша установка ещё не настроила его.
3. Включите расширения, о которых сообщает Composer. Для локальных примеров нужны mbstring, Sodium, PDO и pdo_sqlite, а также расширения, требуемые фреймворком и тестами. `php --ini` показывает конфигурацию, которую действительно читает терминал.
4. Установите Composer через [официальный установщик Windows](https://getcomposer.org/doc/00-intro.md#installation-windows), выбрав нужный исполняемый файл PHP.
5. Закройте и снова откройте PowerShell, затем выполните приведённые ниже команды проверки.

Если `php` не распознаётся, выполните `where.exe php` и проверьте PATH. Если команда находит PHP 8.2, изменение кода Elang не устранит несовпадение версий.

## Настройка macOS

Используйте способ установки, описанный в [руководстве по установке PHP в macOS](https://www.php.net/manual/en/install.macosx.php). Поддерживаемый менеджер пакетов обычно является самым коротким путём к поддерживаемой CLI-установке. Установите Composer по [официальным инструкциям для Unix/macOS](https://getcomposer.org/doc/00-intro.md#installation-linux-unix-macos).

Следуя инструкциям установщика Composer, используйте контрольную сумму с его официальной страницы загрузки. Не полагайтесь на контрольную сумму из старого учебника. После изменения PATH откройте новый терминал и проверьте оба исполняемых файла.

## Настройка Ubuntu 24.04

В Ubuntu 24.04 стандартные пакеты PHP дают подходящую отправную точку:

```bash
sudo apt update
sudo apt install php-cli php-mbstring php-xml php-sqlite3 php-curl php-zip unzip
```

Затем следуйте официальным инструкциям по установке Composer. В другом дистрибутиве или выпуске имена пакетов и версии PHP по умолчанию могут отличаться. Проверьте `php -v`: Elang требует 8.3+, даже если менеджер пакетов успешно установил более старую версию PHP.

Подключение SQLite по умолчанию не требует отдельного сервера базы данных. Позже, разобравшись в основном жизненном цикле запроса, можно добавить MySQL или PostgreSQL.

## Проверка инструментов

```bash
php -v
php --ini
php -m
composer --version
```

Ожидаемый результат: PHP 8.3+ в пределах ветки PHP 8.x, доступный для чтения путь конфигурации CLI, необходимые расширения и Composer 2. Ошибка отсутствующего расширения называет компонент, который нужно включить или установить.

## Создание приложения через Composer

Откройте терминал в родительском каталоге, где хотите разместить проект. Выполните:

```bash
composer create-project --repository=https://elangphp.com/packages elang/elang my-app 0.1.0-dev
cd my-app
php elang doctor
php elang serve
```

Composer создаёт проект, устанавливает зависимости, генерирует ключ и проверяет окружение. Откройте `http://127.0.0.1:8000`, когда сервер выведет этот адрес. Оставляйте терминал работающим, пока используете локальный сайт; нажмите Ctrl+C, чтобы остановить его.

Рабочая команда предварительной версии включает репозиторий Composer Elang, поскольку пакеты ещё не опубликованы в Packagist. Рабочая копия Git или вручную распакованный архив не нужны.

## Более короткая команда после однократной настройки

[Руководство по установке](/docs/v0.1/installation) объясняет настройку глобального CLI. После неё `elang new my-app` создаёт ещё один проект. В каталоге приложения `php elang doctor` и `php elang serve` запускают консоль этого приложения.

## Проверьте понимание

Теперь вы должны знать, какой исполняемый файл PHP использует терминал, где находится composer.json проекта, как запускать и останавливать локальный сервер и как читать отчёт doctor. Продолжите с [необходимых основ PHP](/learn/php-basics). Если команда завершилась ошибкой, обратитесь к [руководству по устранению неполадок](/docs/v0.1/troubleshooting), прежде чем переходить дальше.
