# Почта

Elang связывает Symfony Mailer с настроенным транспортом. Сообщения не отправляются, пока не настроен реальный транспорт.

## Настройка транспорта

```dotenv
MAILER_DSN="smtp://user:password@smtp.example.com:587"
```

Кодируйте учётные данные в формате URL. Настраивайте шифрование и параметры провайдера согласно документации Symfony Mailer. Транспорт по умолчанию `null://null` намеренно отбрасывает сообщения.

## Отправка сообщения

```php
use Symfony\Component\Mailer\MailerInterface;
use Symfony\Component\Mime\Email;

$message = (new Email())
    ->from('hello@example.com')
    ->to('reader@example.com')
    ->subject('Welcome')
    ->text('Your application is ready.');

$mailer->send($message);
```

Внедрите MailerInterface в сервис приложения. Используйте проверенные адреса получателей и адреса отправителей, контролируемые приложением.

## Модель доставки

Отправка выполняется синхронно. Доставка зависит от настроенного провайдера, DNS, учётных данных и поведения транспорта. Для фоновой доставки зарегистрируйте задание приложения, которое загружает получателя и вызывает внедрённый MailerInterface, затем отправьте его через /docs/v0.1/queues. Автоматическое преобразование писем в задания и каталог шаблонов транзакционных писем не включены.
