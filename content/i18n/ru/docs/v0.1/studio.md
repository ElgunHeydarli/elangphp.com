# Elang Studio

Studio — локальная панель разработки для изучения запросов, маршрутов, запросов к базе данных и писем учётных записей. Она отключена в рабочей среде и отклоняет клиентов не с loopback-адресов даже в локальном окружении.

## Открытие Studio

Запустите приложение командой `php elang serve`, затем откройте `http://127.0.0.1:8000/_elang/studio`. Команда `php elang studio` показывает настроенный адрес.

Используйте APP_ENV=local. В рабочей среде маршруты разработки не регистрируются. Изменение HTTP-параметра не может их включить.

## Запросы HTTP и запросы к базе данных

Панель хранит последние 100 локальных запросов. Подробности запроса включают HTTP-статус, длительность, маршрут, шаблоны запросов в ограниченном объёме и время их выполнения. Привязанные значения SQL исключаются; литералы в кавычках скрываются.

Тела запросов, cookie, заголовки авторизации, параметры строки запроса URL и аргументы исключений не собираются. Сегменты пути, похожие на токены, скрываются. Эти ограничения уменьшают вероятность случайного сбора учётных данных, сохраняя полезный контекст разработки.

## Местоположение ошибок

Запись исключения показывает его тип, местоположение в исходном коде и короткую цепочку вызовов. Проверьте указанные файл и строку, затем обратитесь к закрытому журналу приложения за дополнительным контекстом. Один код статуса не показывает, какая зависимость дала сбой.

Studio не является облачным сервисом мониторинга ошибок. Она использует локальное закрытое хранилище и предназначена для одного окружения разработки.

## Почтовый ящик разработки

Когда локальная почта учётных записей использует пустой транспорт, сообщения шифруются с помощью APP_KEY и сохраняются вне public/. Локальный почтовый ящик показывает письма подтверждения и восстановления, чтобы можно было проверить полный процесс без почтового провайдера.

Для доставки в рабочей среде требуется настроенный SMTP или другой поддерживаемый почтовый транспорт. Локальный почтовый ящик недоступен с рабочего сайта.
