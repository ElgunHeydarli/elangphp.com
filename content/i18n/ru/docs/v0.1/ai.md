# Работа с ИИ

Используйте версионированную документацию, чтобы давать помощникам программирования актуальный и точный контекст Elang. Elang — PHP-фреймворк, а не отдельный язык.

## Начальная точка документации

Откройте `/llms.txt` для краткого указателя. Каждая страница версионированной документации имеет представление Markdown по тому же URL с добавлением `.md`. Раздел head HTML сообщает об этих альтернативных представлениях.

## Соглашения проекта

Репозиторий включает AGENTS.md с архитектурой, командами и границами реализации. Запрашивая изменения, предоставляйте инструментам программирования нужные исходные файлы и документацию.

## Пример полезного запроса

```text
Build an Elang PHP controller for a JSON endpoint.
Read the v0.1 routing, validation, and controllers documentation first.
Use Symfony HttpFoundation requests, Elang Response::json, and
Symfony Constraint objects. Do not assume Laravel facades or an ORM.
Write a test for the invalid-input response.
```

## Ограничения

Публикация документации не обучает модель автоматически и не гарантирует ссылки в поиске с ИИ. MCP-сервер документации с доступом только для чтения доступен по /mcp и через php elang docs:serve. Семантический поиск и специальные расширения редакторов остаются в планах. Текущий API поиска выполняет ограниченный текстовый поиск по локальной документации.

## Подключение сервера документации

Публичный эндпоинт Streamable HTTP с доступом только для чтения — `https://elangphp.com/mcp`. Он предоставляет search_docs и read_doc, а также перечисленные ресурсы Markdown elang://. Для публичной документации токен учётной записи не нужен. Сервер отклоняет браузерные запросы из других источников и не предоставляет инструментов записи или выполнения.

Для локального клиента stdio запустите `php elang docs:serve` из рабочей копии сайта документации. Стандартный вывод содержит только сообщения JSON-RPC. Эта реализация поддерживает протокол MCP 2025-11-25.
