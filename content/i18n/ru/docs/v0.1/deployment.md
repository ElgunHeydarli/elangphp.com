# Развёртывание

Приложения Elang работают на стандартном веб-сервере PHP. Этот сайт использует PHP-FPM за Apache и Nginx.

## Подготовка приложения

```bash
composer install --no-dev --prefer-dist --optimize-autoloader
php elang migrate --force
```

Проверьте миграции и создайте резервную копию базы данных перед изменением рабочей среды. Не устанавливайте инструменты разработки в публичный каталог.

## Окружение

Установите `APP_ENV=production`, `APP_DEBUG=false`, HTTPS-адрес в `APP_URL` и сгенерированный `APP_KEY`. Отдельно настройте учётные данные базы данных и почты. Предоставьте процессу PHP доступ на запись только в `storage/` и необходимые расположения базы данных.

## Корневой веб-каталог

Направьте веб-сервер на `public/`. Передавайте несуществующие пути в `index.php`. Apache может использовать включённый `.htaccess`. Типичный блок location для Nginx:

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```

Добавьте блок PHP-FPM, подходящий вашему серверу. Не открывайте доступ к корню проекта, файлам vendor, метаданным Git, секретам или файлам SQLite.

## Существующий виртуальный хостинг

Если панель управления хостингом фиксирует корневой веб-каталог, храните приложение вне него и копируйте в публичный каталог только содержимое `public/`. Настройте точку входа на загрузку закрытого приложения. Скрипт публикации этого сайта следует такой модели.

## После развёртывания

Проверьте ожидаемые страницы и ответы API, изучите серверные журналы и отслеживайте сбои. Сертификаты HTTPS и заголовки безопасности для статических ресурсов следует настраивать на уровне хостинга. Эта предварительная версия не включает автоматическое развёртывание без простоя или управляемый хостинг.
