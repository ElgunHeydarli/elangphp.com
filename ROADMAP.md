# Elang roadmap

## Available in the development preview

Optional Doctrine ORM with relationships/timestamps/soft deletion/optimistic locking, collections and lazy streams, explicit API resources, outbound HTTP with bounded responses and strict fakes, in-process application testing, custom console commands, HTTP routing, services, middleware, validation, Twig, DBAL transactions/migrations, account authentication, roles/policies, scoped tokens, model repositories, relations, pagination, factories/seeders, Content Studio, local request/SQL/mail Studio, database jobs, UTC scheduling, SSE, authenticated Workerman WebSockets, event replay, CORS, idempotency, OpenAPI, React/Next.js integration examples, React/Next fullstack and SaaS starters, Redis infrastructure, transactional outbox, MFA/passkeys/devices, tenant roles/invitations, private local/S3 files, queued notifications, OpenTelemetry, three-language documentation, and a read-only documentation MCP server.

All eighteen development packages are indexed on Packagist as `dev-main` (alias `0.1.x-dev`). Clean application and global-installer installations are verified; this does not make the preview a stable release.

## Before a stable release

Broader real-application and database contention tests, measured workload capacity, independent security review, API stabilization, release/support policy, and maintained upgrade guidance. Published development microbenchmarks do not prove general superiority or production capacity.

## Planned

Additional broker adapters, semantic documentation search, dedicated editor integrations, and automated upgrade tooling.

These are intentions, not promised availability dates. Production or banking suitability requires application-specific validation and independent review.
