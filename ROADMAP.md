# Elang roadmap

## Available in the development preview

HTTP kernel, router, service container, middleware, Twig views, constraint validation, Doctrine DBAL, migrations, session/CSRF primitives, passwords/encryption, rate limiting, cache, logging, synchronous events and mail, console tooling, application generation, and the documentation website.

## Before a stable release

Broader PHP and database compatibility checks, API feedback, independent security review, release/support policy, Packagist publication, reproducible benchmarks, and complete sample applications.

## Planned

Authentication and authorization, optional ORM integration, queue worker, scheduler, shared storage adapters, documentation MCP server, editor integration, and upgrade tooling.

These are intentions, not promised availability dates. Changes should follow tested use cases and maintainer capacity.
