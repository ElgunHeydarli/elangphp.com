# Elang roadmap

## Available in the development preview

HTTP routing, services, middleware, validation, Twig, DBAL transactions/migrations, account authentication, roles/policies, scoped tokens, model repositories, relations, pagination, factories/seeders, Content Studio, local request/SQL/mail Studio, database jobs, UTC scheduling, SSE, authenticated Workerman WebSockets, event replay, CORS, idempotency, OpenAPI, React/Next.js integration examples, complete application starters, three-language documentation, and a read-only documentation MCP server.

## Before a stable release

Broader real-application and database contention tests, measured workload capacity, independent security review, API stabilization, release/support policy, Packagist publication, and maintained upgrade guidance. Published development microbenchmarks do not prove general superiority or production capacity.

## Planned

Optional ORM integration, distributed cache/session/rate-limit/broker adapters, semantic documentation search, dedicated editor integrations, and automated upgrade tooling.

These are intentions, not promised availability dates. Production or banking suitability requires application-specific validation and independent review.
